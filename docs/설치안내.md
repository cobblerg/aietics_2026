# 설치·배포 안내

AI 윤리 탐험을 우리 학교 구글 계정에 설치하는 방법입니다. 처음 설치는 20분 정도 걸립니다.

## 준비물
- 학교 구글 계정(Google Workspace). 이 계정이 **관리자**가 됩니다.
- 이 저장소의 `dist/apps-script/` 폴더 파일 3개: `Code.gs`, `Core.gs`, `Index.html`
  - 없거나 오래됐으면 `python build.py` 로 다시 만듭니다.

## 1. 처음 설치

1. 새 **구글 스프레드시트**를 만들고 **[확장 프로그램] → [Apps Script]** 를 엽니다.
2. 편집기에 파일 3개를 만들고 `dist/apps-script/` 의 내용을 그대로 붙여넣어 저장합니다.

   | 편집기 파일 | 종류 | 붙여넣을 내용 |
   | --- | --- | --- |
   | `Code.gs` | 스크립트 | `Code.gs` |
   | `Core.gs` | 스크립트 | `Core.gs` |
   | `Index` | HTML (이름은 반드시 `Index`) | `Index.html` |

3. 위쪽 함수 선택 칸에서 **`setup`** 을 골라 **실행**하고 권한을 허용합니다.
   - `학생`·`사용자`·`설정`·`등록양식` 시트가 만들어집니다.
   - 실행한 계정이 `사용자` 시트에 **관리자**로 등록됩니다.
4. **[배포] → [새 배포] → 유형: 웹 앱**
   - 실행 사용자: **나(소유자)**
   - 액세스 권한: **(학교 도메인) 내 모든 사용자**
5. 나온 **웹 앱 주소**(`…/exec`)를 학생에게 안내합니다.
   - 이 주소는 저장소·공개 문서에 올리지 않습니다.

## 2. 학생·교사 등록

- **학생**: 교사 화면 → **일괄 등록**. `등록양식` 시트 형식(학번·이름·이메일·학급)을 따릅니다. 이메일은 학교 구글 계정이어야 합니다.
- **담임 교사**: 교사 화면 → **권한·설정**에서 이메일·이름·담당학급을 추가합니다.
- (선택) 화면 확인용 샘플 학생 24명: 편집기에서 `addSampleStudents` 실행. 확인 후 `학생` 시트에서 지웁니다.

## 3. 배포 전 확인 (`/dev` 테스트 주소)

- [ ] 관리자 계정으로 교사 화면이 열린다.
- [ ] 학생 계정으로 3차시를 열고 사전 퀴즈, 장 이동, 학습 확인이 된다.
- [ ] 영상 장에서 영상 시청 확인이 동작한다. (데모 모드에서는 꺼져 있으므로 배포본에서만 확인 가능)
- [ ] 학생 행의 진행 기록이 `학생` 시트에 저장된다.
- [ ] 등록되지 않은 계정은 막힌다.

## 4. 고친 뒤 다시 배포

1. `src/` 를 고치고 `python build.py` 를 실행합니다. (`dist/` 는 직접 고치지 않습니다.)
2. Apps Script 편집기의 세 파일을 `dist/apps-script/` 내용으로 바꿉니다.
3. **[배포] → [배포 관리] → 편집(연필) → 버전: 새 버전 → 배포**
   - 같은 배포를 새 버전으로 올려야 **주소가 바뀌지 않습니다.** '새 배포'를 만들면 주소가 달라집니다.

## 5. 설정 (교사 화면 → 권한·설정)

| 항목 | 뜻 |
| --- | --- |
| `chapterSec` / `videoSec` | 장·영상 장 최소 학습 시간(초) |
| `explainAfter` | 해설을 보여 주는 시점 |
| `videoWatch` | 영상 시청 확인 사용 여부 |
| `start상/중/하` | 사전 퀴즈 수준별 시작 단계 |
| `levelHi` / `levelMid` | 수준을 나누는 점수 기준 |

`설정` 시트를 직접 고쳐도 되지만 교사 화면에서 바꾸는 것을 권장합니다.

## 6. 문제 해결

| 증상 | 확인할 것 |
| --- | --- |
| `setup을 먼저 실행해 주세요` | 편집기에서 `setup` 실행 |
| `Invalid or unexpected token` | `Index.html` 을 `dist/` 최신본으로 다시 붙여넣기 (앱 코드는 Base64로 묶여 있음) |
| 코드를 고쳤는데 학생 화면이 그대로 | 새 버전으로 재배포했는지 확인 |
| 학생이 접속하지 못함 | 학교 계정으로 로그인했는지, `학생` 시트 이메일이 같은지 확인 |
| 영상이 완료로 안 넘어감 | `/dev` 주소에서 확인. `videoWatch` 설정과 시청 시간 확인 |

## 데모 모드
`dist/preview.html` 을 브라우저로 열면 서버 없이 샘플 계정(관리자·담임·학생)으로 화면을 둘러볼 수 있습니다. 기록은 그 브라우저에만 저장됩니다.
